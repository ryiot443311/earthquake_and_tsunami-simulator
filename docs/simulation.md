# シミュレーションの仕組み

このシミュレーターが震度・緊急地震速報・津波をどのように計算しているかの説明です。どれも実際の気象庁の処理を簡略化した**近似**で、実際の地震・津波の予測には使えません。

関数名・定数名は `index.html` 内の名前です（コードを読むときの目印）。

---

## 1. 震源と断層

- 指定できるのは震央（経度・緯度）・深さ・規模（M2.0〜M10.0）・走向・断層の型（内陸／海溝型／スラブ内）・破壊の進み方。
- 断層面は走向方向に長さL、傾斜方向に幅W。海溝型は低角、スラブ内は中角、内陸は高角で上端を浅くする（上端は深さ3km）。
- 震度の計算に使う距離は、地点から**傾斜した断層面までの最短距離**（3次元）。
- 複数の地震は最大8つ（`QMAX`）、発生のずれは最大4200秒（`DTMAX`）。どの30秒間にも地震は4つまで。

## 2. 震度の推定

### 2.1 揺れの大きさ（`pgvBase` → `intensity`）

1. **工学的基盤の最大速度**: 司・翠川（1999）の距離減衰式。
   `log PGV = 0.58Mw + 0.0038D + d − 1.29 − log(X + 0.0028·10^(0.5Mw)) − 0.002X`
   （D＝深さ、X＝断層最短距離、d＝断層の型による補正）。M8.3を超える分は0.15倍に抑える（巨大地震での頭打ち）。
2. **地表の最大速度**: 基盤の値に、J-SHIS 表層地盤の**増幅率**を掛ける。
3. **地盤の非線形性**（`siteLog`）: 強い揺れ（基盤の最大速度が約20cm/s超）では軟らかい地盤の増幅を割り引く（最大で半分まで）。
4. **計測震度への換算**（`iFromLogV`）: 藤本・翠川（2005）の2次式。低い震度は翠川ほか（1999）の式に滑らかにつなぐ。

### 2.2 ばらつきと補正

- **空間的なばらつき**（`noiseAt`）: 地点ごとに対数正規のばらつき（既定 σ＝0.3）を足す。
- **異常震域**: 火山フロントより背弧側（日本海側）では深い地震の揺れを弱め、前弧側（太平洋側）では伝わりやすくする。
- **市区町村の震度**: 役所付近の格子と、区域内の観測点（K-NET・KiK-net・気象庁）の格子の最大。ばらつきの最大値を拾いすぎないよう、ばらつきを除いた値で最大を選んでから、その市区町村のばらつきを足し直す。
- 揺れ（S波）がまだ届いていない地点には震度を出さない。
- **直近の地震の観測震度への補正**（`obsBuild`）: 気象庁の観測点ごとの震度を、観測点名の先頭（市区町村名）で市区町村に結び付ける（報告の無い市区町村は震度0とみなす）。各市区町村の格子と役所の位置の計算値がその階級に入るよう補正値を繰り返し求め、2〜7km（都市部ほど狭い）の広がりで周りへなめらかに広げて足す。震源・M・深さを変えると補正しない。
- **直近の地震の発震機構**: USGS のモーメントテンソル解があれば、2つの節面のうち（逆断層なら傾斜の緩い方）の走向・傾斜を使う。海の深さ60km以内で、傾斜35°以下の逆断層はプレート境界、それ以外は海のプレート内とする。

### 2.3 地震波の伝わる速さ（`vP`・`vS`）

- P波の平均速度は、遠く・深くなるほど速くなる近似（JMA2001走時表に合わせた式、約6.3〜8.8km/s）。S波はP波の1/1.73。
- P波・S波の円は、その地震で震度0.5以上になる最も遠い地点にS波が届いて5秒後まで残す。

### 2.4 長周期地震動階級

- 地表の最大速度から、規模が大きいほど長周期成分が多くなる比で絶対速度応答（周期1.5〜8秒）を換算し、主な堆積平野で上乗せする。
- 実際の記録（熊本2016・能登2024で階級4、福島県沖2022で宮城県北部が階級4）に合うよう調整。
- 室内の階数を選ぶと、建物の1次モードの形（上の階ほど大きい）を掛けて階ごとの階級を出す（固有周期1.6秒未満の建物は対象外）。

## 3. 緊急地震速報

### 3.1 観測網と検知

- 観測網: K-NET・KiK-net・S-net・DONET・N-net・気象庁ケーブル（詳細設定で個別にオン／オフ）。
- **P波の検知**: 観測点にP波が届いた時刻＋読み取りと伝送の遅れ（観測点ごとに約0.1〜0.6秒）。
- 第1報は検知から処理の遅れ（既定3秒）の後。続報は検知点が増えるたびに出る。

### 3.2 震源とMの推定（`estimate`）

- **震源の誤差**: 初期誤差（既定15km）。最も近い観測点が遠いほど（海域など）誤差が大きい。検知点が増え、時間が経つほど小さくなる。
- **推定Mは時間とともに伸びる**（`mRup`）: 断層の破壊が進むにつれて大きくなる。
- **巨大地震の過小評価**（`e.mBias`）: 破壊が長く続く巨大地震は、緊急地震速報の段階ではMが決まりきらない。M7.5を超える地震は (0.2〜0.4)×(M−7.5) だけ小さく推定し、最終報でも「やや過小」で止める（上限は設けない）。
- **最後まで残る誤差**（`e.mErr`、±0.35程度）。
- 正確なM（モーメントマグニチュード）は後の情報で段階的に更新する（認知から約7分・20分・40分で速報値、約60分で実際のM。2011年の M7.9→8.4→8.8→9.0 の形）。

### 3.3 予測震度と警報（`predictAreas`）

- 地域ごとの予測震度＝max（震源とMからの予測、PLUM法による予測）。
  - **震源とMからの予測**: 推定した震源・Mで、地域内の市町村の震度を2.1の式で計算（点震源に近い扱い）。
  - **PLUM法**: 地域内の各地点から半径30km以内の陸上観測点で実際に観測された揺れ（リアルタイム震度）を、地盤の差で補正してそのまま予測に使う。自分の地震の揺れだけを使う。
- **警報の条件**: 2点以上の観測点で検知し、どこかで予測震度5弱以上（`warnTh`＝4.5）または長周期地震動階級3以上。そのとき予測震度4以上（`areaTh`＝3.5）の地域を対象にする。
- **警報の続報**は、まだ警報が出ていない地域で新たに基準以上が予測されたときだけ出し、対象地域を追加する。
- 深い地震（150km超）は震源からの予測を使わない（設定で変更可）。

### 3.4 実際の誤差の再現

- **誤報と取消報**: 雑音による誤検知を試すボタン。取消報はNHKの画面に合わせ、小地図なしの枠を画面の左右中央に出す。
- **2つの地震の誤認**（`setMis`、2018年1月5日の茨城県沖と富山県西部の例）: 離れた（60km以上）2つの地震のP波検知が15秒以内に重なると、ときどき（約15〜25%、毎回ランダム）1つの地震として処理する。後の地震で揺れた観測点を先の地震の震源からの距離で解釈するため、Mを過大（場合により過小）に推定し、数秒後に別の地震と判別して戻す。
- 乱数は「地震発生」のたびに変わる。時刻を戻したときは同じ結果を再現する。

### 3.5 表示

- 警報は最低15秒表示してから震度速報へ切り替え、切替後も縦テロップで残す。
- テロップは「最終報から30秒後」と「対象地域のすべての市町村へのS波到達」の両方を過ぎたら消す（シミュレーター内の時間）。
- テロップの比率はNHKの実際の画面（16:9）を測った値に合わせている。
- **対象地域の並び**: 最初の警報は予測震度の大きい順。その後の続報では既に出ている地域・地方の順番を変えず、新しく加わった府県だけを後ろに足す。
- **地域名は基本2行まで**: 3行以上になるときは北海道の地域（道東・道南など）を「北海道」にまとめ、それでも収まらない広い範囲は地方名（東北・関東など）で表示する。

### 3.6 遠地地震（`farSetup`・`showFar`）

- 推定した震央が日本の陸地から800km以上なら、震度に関係なく遠地地震として扱う。震度速報は出さず、微弱なP波から遠地と判断した時点で「遠地地震に関する情報」を出し、その後10〜15分で続報・最終報と詳しくする。
- 精度の低い緊急地震速報が出る場合もある。海外機関（PTWC・USGS）の解析の引用、海外の津波観測による予報の引き上げ、巨大地震の表面波による遠方の弱い揺れも再現する。
- 津波は第1報で「調査中」とし、予報は低めに出して観測で引き上げる（慎重な運用）。

## 4. 震度速報・地震情報

- 地震ごとに、震度3以上の地域にS波が届いてから（最初のS波が陸に届いてから）発表する。発生中の地震の緊急地震速報が終わるまで（最大20秒）待つ。
- 震度はその地震の揺れだけで出す（操作卓の「各地域の震度」は全地震の累積）。

## 5. 津波

### 5.1 津波警報・注意報（`computeTsunami0`）

1. **初期水位**: 断層を幅方向に4分割し、Okada（1985）の矩形断層の式で海底の上下変位を海の格子（0.1度）ごとに求める。地震モーメント M0＝10^(1.5Mw+9.1) N·m、剛性率は内陸30GPa／海溝・スラブ内40GPa、ポアソン比0.25。海溝型は浅い側ほど大きくすべる。長い断層（約M8.3以上）の実際の津波は、大きくすべる場所と集中の度合い（一様〜両端ほど小さい）を地震ごとに乱数で決める（シナリオは実際の地震・想定の形に固定。東日本大震災は宮城沖に集中、南海トラフは一様）。海岸の高さは、その正面（走向に沿って近い所）の変位でほぼ決まるよう、走向に沿って離れた変位ほど弱める。気象庁の予報（データベース方式）と予想表示は一様すべり。
2. **海岸の高さ**＝初期水位 × グリーンの法則（水深比の1/4乗）× 幾何減衰（√(a/(a+距離))）× 地形増幅（予報区内の高い所として1.4倍）。水深は海岸からの距離で近似（30m＋25m/km、上限3500m）。
3. **到達時間**: 水深から求めた波速（√gh）を、波源から海岸まで海の経路に沿って足し合わせる。九州の西（有明海・八代海を含む）・瀬戸内海（伊予灘・周防灘を含む）・大阪湾・伊勢湾・三河湾など浅い海に面した海岸は、浅い海の中を通る道のりだけ浅い海の速さで数える。
4. **経験式で確認**: 阿部の式（遠地 log H＝Mw − log Δ − 5.80、近地の上限 log H＝0.5Mw − 3.30）と大きく違う値は0.35〜2.2倍の範囲に収める。
5. **地形の扱い**:
   - **回り込み（回折）**: 半島・島の陰へ回り込む遠回りの分だけ弱める。幅数kmの半島を波が突き抜けないよう、陸をまたぐ経路は大きく遠回りとして扱う。
   - **狭い所の弱まり**: 海峡・湾の入口など狭い所を通るほど弱めるが、湾や内海の中に入った波は反射を繰り返して残るので、弱まりは頭打ちにする。海岸のすぐそばが狭く見える分は数えない。津軽・宗谷海峡は全長にわたって少しずつ弱める。有明海・八代海の口（早崎瀬戸、八代海の南の口）は、通ると約1/2.5に弱める（中から出る津波も、外から入る津波も）。
   - **断層の向き（指向性）**: 長い断層（約M8.5以上）の津波は断層に直交する向きに集中するので、断層の端より先の海岸は、端から見た角度が大きいほど弱める（日本から遠い地震には使わない）。
   - **湾の形による増幅**: 湾の奥・V字形の湾ほど高く、まっすぐな海岸は低めに配る。近くの海岸どうしは数kmでなだらかにつながるようにする。
   - 太平洋側の波源の津波は、日本海側では注意報までにとどめる（日本海側にも断層がある場合を除く）。
6. **予報区の割り当て**: 海岸の各点を、面している海に合った津波予報区に割り当てる（陸奥湾・内浦湾・知床半島・佐田岬半島・佐賀関半島・島原半島など、細い陸地の両側を区別）。境は気象庁の市町村対応表の岬・市町村に合わせる（例: 千葉県内房と九十九里・外房は野島崎南端、鹿児島県東部は大隅半島の太平洋側だけで錦江湾は西部）。

上の計算は「実際に起きる津波」（観測値の元）。**発表する予報**は別に、気象庁の津波予報データベース方式をまねて求める（`tsuDb`）。

- **データベースの検索**: 発表時点で推定した震源（実際から少しずれる）・深さ・Mを使う。震央を囲む緯度・経度0.5度の格子の4点（海の点）に、傾斜45度の逆断層を置いて計算し、予報区ごとに最も高い値を採る（最大危険度法）。震央が陸なら震央に断層を置く。このため予報は実際より広く・高めに出やすい。
- **巨大地震**: M8を超える地震の第1報は、その海域で想定される最大のMで見積もって「巨大」「高い」で発表。海溝・トラフ（千島・日本・伊豆小笠原・相模・南海・南西諸島）から250km以内の海で起きたプレート境界の地震は M9.0、有明海・瀬戸内海・九州の西などの浅い内海・大陸棚は推定のMのまま、ほかは推定のM＋0.5（上限 M8.5）。約15分後にその時点のMで数値に更新する（区分は下げない）。
- **周辺の予報区**: 大津波警報の隣は少なくとも津波警報、津波警報の隣は少なくとも注意報にする（瀬戸内海など入り組んだ所で、大津波警報と注意報が隣り合わないように）。狭い海を挟んで向かい合う予報区（岡山県と香川県など）は同じ区分にそろえる。
- **観測による引き上げ**: 観測された津波が予報より高ければ、1〜4分後により上の区分へ引き上げ・追加する。
- **発表基準**（気象庁）: 予想高さ0.2m以上1m以下＝注意報、1m超3m以下＝警報、3m超＝大津波警報。注意報に満たない小さな津波は「若干の海面変動」。
- 発表は地震を認知（緊急地震速報の第1報）してから約3分後。M8を超える巨大地震は、第1報では高さを「巨大」「高い」の言葉で出し、約15分後に数値へ更新する。

### 5.2 津波観測に関する情報（`tobsBuild`・`tobsTick`）

- **観測点**: 気象庁の津波観測点459点（沿岸191・沖合268）。
- **沿岸**: 観測点のある都道府県の、最も近い海岸の津波の値を1.4で割り（検潮所は予報区内の高い所より低い）、観測点ごとのばらつき（対数正規、σ0.3）を掛ける。
- **沖合**: 波源から海の経路で届く津波を、観測点の水深でグリーンの法則により小さくした値（沿岸より高くならないよう上限あり）。
- **波の形**: 第1波の到達から周期（波源の幅で8〜50分）で繰り返し、何番目かの波で最大になってから弱まる。湾・内海の中の観測点は、反射が重なって最大の波が後ろになりやすく、長く続く。押し波・引き波、第1波が小さいときの「識別不能」、測定範囲超え（「以上」）、欠測（2%）も再現。
- **発表**: 観測から約2分後の値で、変化があれば発表（続報は5分以上あける）。表記は気象庁のルール（「観測中」「推定中」「微弱」「上昇中」など）に従う。
- 津波注意報以上が出る地震は、波が収まるまで（発生から最長4時間）シミュレーションを続ける。

### 5.3 地図の津波の波の広がり（`wvBuild`・`wvPaint`）

- 「震度｜津波」で津波を選んでいる間だけ、海の格子（0.1度）ごとの海面の上下を地図に描く（上昇＝オレンジ〜赤、下降＝水色〜青）。凡例はPC版（幅1000px以上）だけ。
- 到達時刻: 実際の津波の波源から海の上の最短経路の道のりを、水深に応じた波の速さ（√gh）で割る。水深は海岸からの距離で増え、外洋は日本海溝・千島海溝・伊豆小笠原海溝より東の太平洋で約6000m、南海トラフ・南西諸島海溝より外のフィリピン海で約4500m、ほかは予報の計算と同じ（表示だけの値で、警報・観測の計算は変えない）。
- 振幅: 波源の上下変位 × 幾何減衰 × グリーンの法則 × 経路の弱まり。第1波（隆起なら上昇、沈降なら下降）から周期（8〜50分）で上下しながら弱まる。
- 海の格子（東経119〜157度・北緯19〜51度）の外は、地図で見られる範囲（東経89〜189度・南緯13〜北緯77度）まで0.25度の粗い格子で続きを描く（`wvBuildOut`）。外側は外洋として扱い、格子の中の到達時刻と格子の外の波源から16方向の最短時間で広げ、振幅は同じ式を道のりを延ばして続ける。画面に格子の外が見えているときだけ計算する。

## 6. 室内の揺れ（3D）

1. **地表の加速度波形**（3成分）を合成: ω²モデルのスペクトル＋距離減衰＋地盤のピーク。包絡線はP波→S波の主要動→減衰。
2. **振幅の合わせ込み**: 合成波形から気象庁の計測震度（フィルター後の合成加速度で、合計0.3秒以上続く値 a0 から I＝2log₁₀(a0)＋0.94）を計算し、推定震度と一致するよう倍率を決める。
3. **建物の揺れ**: 建物の1次モードを1質点系（Newmark β法、β＝1/4）で計算し、指定した階の床の揺れを求める。
4. **家具・物**: 剛体の衝突・摩擦・転がり、背の高い家具のしなり（固有周期0.22秒・減衰3.5%）、本が前へ倒れる動き、扉・照明・落下物を計算する。落下・移動・転倒の程度は気象庁の震度階級関連解説表に合うように調整している。
5. **転倒防止対策**（設定で選択）: 突っ張り棒・ベルト・耐震ジェルは、かかる力が限度を超えると外れる・はがれる。棚板の滑り止めシートと扉のラッチも再現する。
- 計算は揺れの継続時間（6τ＋6秒）まで行い、最後の3秒で揺れを0に絞る。
